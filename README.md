# Rust-Galaga-Remake
Remade Classic Game Galaga using Rust

Using the Rust programming language and the macroquad rust game library
I remade Galaga for a class project to the best of my ability and time constraint
The game gives you 4 ships at the beginning of the game
A set number of enemy ships (colored squares) bounce back and forth on either side of the screen
I could not figure out the algorithm for the ships flight patterns like the actual game so they just move side to side
The ships shoot at you at increasing speeds as the rounds go on
Once all ships are defeated the next round begins with more enemy ships


To run the game download the file and enter "cargo run" into the terminal
this will generate all other files needed and the game will start
